# ATLAS SOFTWARE SOLUTIONS

# Sprint 0 --- Developer Onboarding

**Codename:** Ignition\
**Division:** Cloud Engineering\
**Duration:** Week 1\
**Version:** 1.0.0

------------------------------------------------------------------------

# Sprint Goal

> Successfully onboard every Junior Software Engineer into Atlas
> Software Solutions and prepare them to begin building cloud-native
> software applications.

------------------------------------------------------------------------

# Learning Outcomes

By the end of Sprint 0 students will be able to:

-   Explain the purpose of Atlas Software Solutions.
-   Describe Software as a Service (SaaS).
-   Differentiate between IaaS, PaaS, and SaaS.
-   Explain why cloud computing has transformed software development.
-   Configure a professional development environment.
-   Create and configure GitHub.
-   Join the Atlas GitHub Organization.
-   Complete their first engineering task.

------------------------------------------------------------------------
